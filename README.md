# Linear System Resolver by Cramer's Rules
Python project that solves 3x3 and 2x2 linear systems using Cramer's Rule and applies a profit function to obtain the total profit.

## :hammer_and_pick: Features
- Solve linear systems.
- Calculates 2x2 and 3x3 deterinants.
- Replaces columns (Cramer)
- Calculate the profit function

## :rocket: How to run
```bash
python main.py
```
